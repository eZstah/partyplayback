# Continuing Bean

Read `docs/bean/README.md`, `VISION.md`, `ARCHITECTURE.md` and `HANDOFF.md` from the
repository root before substantial cat-engine work. This is one continuing
character engine: preserve the useful rig and choreography and improve a
bounded capability at a time. Keep exactly one active black cat and the plain
wordmark unless the user changes that direction.

Use `index.js` for page integration and `runtime.js` for animation time, random
choices and owned effects. Preserve memory compatibility. Keep pure decisions
testable and distinguish runtime checks from rendered visual evidence.

Update the handoff with the actual checkpoint, tests, limitations and next task.
Every push to `main` deploys youple.tv, so unless the user asks you to
publish, open a pull request for each increment. Bean is calm by default (see VISION.md):
keep him mostly resting and keep `test/cat-pacing.test.js` passing. Check the current
handoff and conversation; current and later user instructions take precedence.
